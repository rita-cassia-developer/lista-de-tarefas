# 🚀 Lista de Tarefas

[![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)](https://github.com/rita-cassia-developer/lista-de-tarefas)

## 📝 Descrição do Projeto

Este projeto é uma aplicação simples de **Lista de Tarefas** desenvolvida para praticar e consolidar conhecimentos em desenvolvimento web front-end. O objetivo é criar uma interface intuitiva onde o usuário pode adicionar, remover e marcar tarefas como concluídas, demonstrando habilidades em manipulação do DOM e lógica de programação.

## ✨ Funcionalidades

- **Adicionar Tarefas:** Permite inserir novas tarefas na lista.
- **Marcar como Concluída:** Opção para marcar tarefas como finalizadas.
- **Remover Tarefas:** Funcionalidade para excluir tarefas da lista.
- **Interface Intuitiva:** Design simples e fácil de usar.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura básica da página e elementos da lista de tarefas.
- **CSS3:** Estilização para um layout moderno e responsivo.
- **JavaScript Moderno:** Lógica para adicionar, remover e gerenciar o estado das tarefas.
